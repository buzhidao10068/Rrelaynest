爬虫 · Cloudflare Workers

Cloudflare Workers 部署

定时由 Cron Triggers 触发(在 wrangler.toml 配置,不能在此页运行时修改);不支持自建代理,所有请求强制直连;受 Workers 的 subrequest / CPU 时间限制,并发不宜过高。

爬取设置

余额爬取的全局行为;单站可在编辑中覆盖。

启用定时爬取

由 Cloudflare Cron Triggers 按下方表达式周期性爬取。

Workers 的 cron 最小粒度 1 分钟。此值不会在运行时热更新,需写入 wrangler.toml 后重新部署。

[triggers]
crons = ["*/30 * * * *"]

出站代理 · 不支持

Workers 运行时无法连接自建代理(http/https/socks5 均不可用),所有站点强制直连。代理功能仅 Docker 部署可用。

受 subrequest 上限(免费 50、付费 1000 /次调用)约束,建议 ≤ 6,过高易触及单次调用配额。

受 Workers CPU 时间限制,单站超时不宜过长(建议 ≤ 30 秒)。

爬虫 · Docker Node / Docker

Docker / Node 部署

定时由 node-cron 驱动,爬取间隔可随时修改、即时生效;支持 http/https/socks5 出站代理(在代理页配置);并发/超时/重试可自由配置,无平台硬限制。

爬取设置

余额爬取的全局行为;单站可在编辑中覆盖。

启用定时爬取

由 node-cron 按下方间隔周期性爬取所有站点余额。

两次自动爬取之间的最小间隔,修改后即时生效,无需重启。

出站代理 · 支持

支持 http/https/socks5。爬取/签到经代理出网,在代理页统一管理。

同时爬取的站点数量;无平台硬限制,过高仍可能触发站点风控。

单个站点请求超过该时长视为失败。

失败站点按此次数退避重试。

测活

站点连通性检测

测试连接=探测响应耗时;渠道测试=发一句测活词看模型能否正常回复(演示为 mock 结果)。

测活词

渠道测试时发给模型的话,模型正常回复即判为存活。为站点单独绑定某词,或选一条作全局默认;未绑定的站点走全局。

全局默认词

未单独绑定测活词的站点默认用这条。

代理 Node / Docker

Workers 运行时无法连接自建代理,所有站点将强制直连。代理配置仅在 Node/Docker 部署下生效。你仍可在此查看/编辑配置,但不会实际生效。

代理池

管理多个出站代理。为站点单独绑定代理,或在上方选一个作全局出网;未绑定的站点走全局,全局设为直连则不经代理。

全局代理

关于 Rrelaynest

中转站余额与签到管理面板。

应用Rrelaynest
版本 v1.0.0
部署Cloudflare Workers / Docker
推荐规模 ≤ 20 用户 默认存储

默认使用 SQLite/D1(单文件锁、调度串行、鉴权每请求查库),适合 约 20 个用户、每人数十~数百站点的小规模自用。更大规模请升级到 libSQL/Turso 或 Postgres(业务层已隔离,仅换存储适配)。
